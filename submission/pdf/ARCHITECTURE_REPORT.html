مشروع مادة البرمجة المتوازية

اسم المشروع: محرك Backend للتجارة الإلكترونية عالية الأداء
التقنية: Laravel 13 + Octane (Swoole) + Sanctum + Queues

1. فكرة المشروع

نظام تجارة إلكترونية يخدم آلاف الطلبات المتزامنة مع الحفاظ على سلامة البيانات (المخزون، الرصيد، الطلبات) عبر آليات تزامن، طوابير، كاش موزّع، ومراقبة أداء.

3. البرمجة الجانبية (AOP) — ConcurrencyAspect

الكلاس App\Aspects\ConcurrencyAspect يطبّق نمط Around Advice على نقاط التزامن:

  • before() — عداد دخول لكل نقطة
  • after() — قياس المدة (ms) ونجاح/فشل
  • around() — يغلف callback كامل مع تتبع metrics

يُستخدم في: InventoryService، SimulatedPaymentService، LoadBalancerService، وConcurrencyTracingMiddleware لكل طلب HTTP.

6. تدفق الطلب (Checkout)

POST /api/order
  → CapacityControlMiddleware (acquire slot)
  → CircuitBreakerMiddleware (guard orders)
  → CreateOrderAction::handle
       → DB::transaction
            → lock user + cart
            → InventoryService::reserveStock (pessimistic)
            → create order + lines
            → SimulatedPaymentService::charge
            → clear cart
       → dispatch GenerateOrderInvoiceJob
       → dispatch SendOrderNotificationJob
  → release capacity slot
